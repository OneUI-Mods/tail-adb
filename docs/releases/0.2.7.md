許可済みPCへの接続時に、実際には接続できているのに認証失敗と表示される問題を改善しました。

別のPCが接続中の場合は、その接続を維持したまま次のPCを待機させ、切断後に引き継ぎます。

Android 16・17の対応済み環境向けです。同じ署名のrelease APKを上書きして更新できます。接続先・許可・自動起動の設定は引き継ぎます。更新後に専用待受を停止・開始し、PCから再接続してください。端末全体の再起動は不要です。更新時にはADB接続が一時切断されるため、進行中の操作を終えてから更新してください。

未知のOS内ADBや未対応のroot環境には対応していません。初めて使うPCは、従来どおり接続許可が必要です。
