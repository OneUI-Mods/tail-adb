# 回線切り替えと通信復旧への対応を改善

Wi-Fiとモバイル回線の切り替え、Tailscaleの再接続で待受を作れない場合、自動で再試行するようにしました。同じTailscale接続が維持されている間は、動作中のADBを不要に切断しません。応答しなくなった接続を解放し、長時間の通信断でも再試行が過剰にならないようにしています。

接続画面から、選択したAndroidユーザーでTailscaleに接続しているかを確認できます。別ユーザーでのみ接続されている場合も区別します。

PC向けの任意の補助コマンドを追加しました。端末の状態通知用TCP窓口と連携し、「TCPは通るのにADBが応答しない」場合に再接続し、それでも復旧しなければ補助コマンド専用のADBサーバーを再起動します。ほかのADBサーバーは終了しません。既存の別ADBサーバーから同じ端末へ接続している場合は、その接続を切ってから補助コマンドを使ってください。

補助コマンドにはPC上のPython 3.10以降、Android Platform Tools、Tailscaleが必要です。`tailadb_watch.py`をダウンロードし、接続画面の「PC側の復旧コマンドをコピー」で表示されるコマンドを実行してください。起動中は接続に使う専用サーバーのポートを表示します。状態通知用ポートはADBポートの次の番号です（65535の場合は65534）。Tailscale以外には公開せず、許可済みホストだけが利用できます。

Android 16・17の対応環境と従来のshell/root許可は維持しています。署名済みrelease APKを上書きし、Tail ADBの待受を一度停止して開始してください。端末やSystemUIの再起動は不要です。通信断の間の実行中コマンド継続は保証せず、到達不能な間や権限が取り消された場合はPC側で再起動を繰り返しません。
