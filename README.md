# Tail ADB

Tailscaleに接続したAndroid端末へ、ADBで接続するためのroot用アプリです。接続先をTailscaleのVPNに限定した待受を作ります。Wi-Fiとモバイルデータのどちらでも利用でき、Android設定の「ワイヤレスデバッグ」のオン・オフとは別に動作します。

**現在は初期開発版です。** 対応対象は、実機で確認したGalaxy S26 Ultra SM-S948Q / Android 16のadbdです。異なるOSの実装では安全のため開始しません。アプリからの起動と、Wi-Fiを切ったモバイル回線での接続、標準ワイヤレスデバッグがオフの状態での接続を実機確認しています。詳しい確認範囲は[検証記録](docs/testing.md)を参照してください。

## できること

- アプリ内のボタンで、Tailscale専用のADB待受を開始・停止。
- 接続コマンドを表示・コピー。
- Tailscaleの切断を検知して待受を停止し、再接続時に作り直す。
- アイコンと状態表示、常駐通知から接続状況を確認・停止。
- Material 3の下部ナビゲーション、日本語・英語、OS言語への追従、アプリ単独の言語選択。

このアプリが作る待受は、確認したTailscaleのIPアドレスとVPNインターフェースだけに結び付けます。**Android標準や他のアプリが開いているADB待受は変更・停止しません。**

## 必要なもの

- 上記の対応端末と、既存のroot環境。
- 端末にインストール・接続済みのTailscale。
- 同じtailnetへ接続でき、ADBが使えるパソコン。
- Androidで既に承認したパソコンのADBキー。

本アプリはroot化、ブートローダーの解除、Tailscaleアカウントへのログインを代行しません。root権限は起動時に自動で要求します。管理側で拒否されている場合は状態に表示されるので、root管理アプリでTail ADBを許可してください。

## 使い方

1. 端末とパソコンをTailscaleへ接続します。
2. Tail ADBを開き、root権限を許可します。
3. ポートを指定して「ADBを開始」を押します。初期値は5555です。
4. 「Tailscaleで接続待ち」と表示されたら、表示されたコマンドをパソコンで実行します。

```sh
adb connect 100.64.0.10:5555
```

アドレスは例です。実際のアプリ表示を使ってください。接続できるかどうかはTailscale側のアクセス制御にも従います。初めてのパソコンは、先に通常のAndroid ADBでキーを承認してください。本アプリは未承認キーを自動許可しません。

アプリを閉じても接続処理は通知付きで続きます。「停止」または通知の停止ボタンで終了します。端末再起動を行う機能や、起動時に自動で待受を開始する機能はありません。

## 制約

- 安全に隔離するため、このADB経由のshell内で行うネットワーク操作には制限があります。通常のAndroidアプリのネットワーク環境は変更しません。
- キー承認のダイアログは、この追加待受からは表示できません。
- 一時rootが失われた場合は、新しい接続処理を開始できません。
- 対応を確認していないadbd・ネットワーク構造・複数のTailscale VPNが見つかった場合は開始しません。
- すべてのADB機能、端末、root実装、OS更新への対応を保証するものではありません。
